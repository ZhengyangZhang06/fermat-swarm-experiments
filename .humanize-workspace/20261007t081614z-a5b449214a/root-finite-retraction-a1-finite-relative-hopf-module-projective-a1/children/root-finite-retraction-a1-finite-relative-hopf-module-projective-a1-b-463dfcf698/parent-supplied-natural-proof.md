## Proof

1. Fix r and write φ for the algebra map. Put m_i=π(e_i), L=S⊗_R M, and P_S=φ(P) entrywise. Define q:S^n→L by q(b)=Σ_i b_i·(1⊗m_i). It is S-linear. It is surjective because, for any pure tensor s⊗m, surjectivity of π writes m=Σ_i a_i m_i, giving s⊗m=Σ_i sφ(a_i)·(1⊗m_i); finite sums of pure tensors exhaust L. Every column of P_S is killed by q because the corresponding column of P is killed by π.
2. Let C=S^n/im(P_S). The map q descends to an S-linear map α:C→L. The R-linear map x↦[φ(x)] from R^n to C kills im(P): if x=P y, then φ(x)=P_S φ(y). Since ker(π)=im(P) and π is surjective, it induces an R-linear map β:M→C with β(m_i)=[e_i], where C is viewed as an R-module through φ. The balanced map (s,m)↦sβ(m) induces an S-linear map β̂:L→C. On each [e_i], β̂α is the identity, and on each s⊗m_i, αβ̂ is the identity. These elements generate C and L respectively, so α and β̂ are inverse. It follows that ker(q)=im(P_S).
3. Write I=D_(n−r)(P_S). The determinant permutation formula gives det(φ(B))=φ(det(B)) for every square submatrix B. The row and column selections have unchanged index sets under entrywise application of φ. The ideal generated by their image determinants is exactly Ideal.map φ J, so I=JS. This also covers size zero, where the determinant is 1, and unavailable sizes, where both generating sets are empty.
4. Apply θ⁻¹ entrywise to coefficient vectors and define q_θ(b)=T(q(θ⁻¹(b))). This is additive. For s∈S, the assumed semilinearity gives q_θ(sb)=T(θ⁻¹(s)q(θ⁻¹(b)))=s q_θ(b), so q_θ is S-linear. It is surjective because each of the three maps defining it is surjective.
5. Let P_θ=θ(P_S) entrywise. Injectivity of T shows q_θ(b)=0 exactly when θ⁻¹(b) lies in im(P_S). This is equivalent to b lying in im(P_θ): apply θ to an equation θ⁻¹(b)=P_S c to obtain b=P_θ θ(c), and apply θ⁻¹ for the converse. Thus ker(q_θ)=im(P_θ).
6. Apply the sibling theorem p05_fr_rhm_presentation_ideals_eq_a5b449214a over S to the two presentations (P_S,q) and (P_θ,q_θ), with the same n,p,r. It yields D_(n−r)(P_θ)=D_(n−r)(P_S). The determinant formula again identifies the left-hand ideal with Ideal.map θ I. Substituting I=Ideal.map φ J proves the exact asserted equality.

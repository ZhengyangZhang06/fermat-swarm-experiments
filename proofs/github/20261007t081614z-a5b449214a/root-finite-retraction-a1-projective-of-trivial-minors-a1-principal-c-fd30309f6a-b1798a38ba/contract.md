## Theorem `Submission.p05_ptm_split_of_away_splits_a5b449214a`

Let R be a commutative ring, M an R-module, and n,p,q natural numbers. Let P be an n-by-p matrix over R and π:R^n→M a surjective R-linear map with ker π=im(P). Let f:Fin q→R have image generating the unit ideal. For each i, put S_i=R[(f_i)⁻¹] and localize modules at powers of f_i. Suppose the induced S_i-linear map π_i:(R^n)_{f_i}→M_{f_i} has an S_i-linear section for every i. Then π has an R-linear section.

## Proof

1. If R is the zero ring, every R-module is zero because m=1m=0m=0, and the zero map is the required section. Otherwise the cover condition forces q>0, since the ideal generated by an empty family is zero. Write F=R^n, let e_j be its standard basis, and put m_j=π(e_j). Surjectivity of π shows that the m_j generate M. The ℓ-th column c_ℓ of P lies in ker π, and every element of ker π is a linear combination of these columns because ker π=im P.
2. Fix i, put f=f_i, S=R[f⁻¹], and use the hypothesized S-linear section σ:M_f→F_f. For localization at powers of f, every element is a fraction x/f^a; moreover x/1=0 precisely when f^b x=0 for some b. These assertions follow from the defining fraction equivalence: x/f^a=y/f^b if and only if some f^c annihilates f^b x-f^a y. They apply to any module, including when S is zero.
3. Write each of the finitely many values σ(m_j/1) as v'_j/f^{e_j}. Take a common exponent e at least all e_j (take 0 for an empty family), and replace v'_j by v_j=f^{e-e_j}v'_j. Thus σ(m_j/1)=v_j/f^e for every j.
4. For each column ℓ, put z_ℓ=Σ_j P_{jℓ}v_j in F. The relation Σ_j P_{jℓ}m_j=0 and S-linearity of σ imply z_ℓ/1=f^e σ(0)=0. For each ℓ choose an exponent annihilating z_ℓ and let t be a common upper bound, taking 0 if p=0. Then f^t z_ℓ=0 for every ℓ. The R-linear map A:F→F defined by A(e_j)=f^t v_j kills each column and hence all of ker π.
5. Consequently A descends to an R-linear map u:M→F satisfying u(π(x))=A(x). Explicitly choose x with π(x)=m and set u(m)=A(x); two choices differ by an element of ker π, which A kills, so this is well defined. Additivity and R-linearity follow by using x+x' and rx as representatives.
6. On every localized generator m_j/1, the localized map u_f takes the value f^t v_j/1=f^{e+t}σ(m_j/1). These generators span M_f over S, since every fraction m/f^a can be expanded using the m_j. Thus u_f=f^{e+t}σ. Composing with π_f and using π_fσ=id shows that w=πu-f^{e+t}id_M becomes zero after localization. For each generator m_j, Step 2 supplies an exponent annihilating w(m_j). Taking a common upper bound c gives f^c w=0 on M, since the m_j generate M.
7. Define N_i=e+t+c+1 and t_i=f^{c+1}u. Then N_i>0 and πt_i=f^{N_i}id_M. This construction works for every i and did not require S to be nonzero.
8. From Ideal.span(range f)=R, the definition of the generated ideal gives coefficients a_i with 1=Σ_i a_i f_i; finite sums over repeated generators can be grouped into this indexed sum. Set L=1+Σ_i(N_i-1). Expand (Σ_i a_i f_i)^L=1 as the finite sum over all sequences of L indices. In each sequence some index i occurs at least N_i times: otherwise the sum of all occurrence counts would be at most Σ_i(N_i-1)=L-1, although it equals L. By commutativity, that summand is divisible by f_i^{N_i}. Choose such an index for each summand and group the finitely many quotients to obtain b_i with 1=Σ_i b_i f_i^{N_i}.
9. Set s=Σ_i b_i t_i, a finite sum of R-linear maps M→F. For every m, π(s(m))=Σ_i b_i π(t_i(m))=(Σ_i b_i f_i^{N_i})m=m. Hence π.comp s=id, as required.

## Key steps

1. Use the presentation to obtain finite lists of module generators and kernel generators.
2. Choose common denominators for the images of generators under each localized section.
3. Annihilate the finitely many relation errors by one power and descend a map M→R^n.
4. Annihilate the remaining section error on the finite generating family.
5. Obtain πt_i=f_i^{N_i}id with positive N_i.
6. Show these powers still generate the unit ideal by a finite expansion and counting argument.
7. Take a linear combination of the power-scaled sections to obtain a global section.
